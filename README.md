# EVE 工业计算器 · 本地版（欧服）

一个跑在你自己电脑上的 EVE 工业工具：通过官方 **ESI** 读取**个人与军团**的工业项目、蓝图和库存，
结合 CCP 官方**静态数据（SDE）**计算材料、任务费用、时间与利润。

- **零依赖**：只用 Python 标准库，不需要 `pip install` 任何东西。
- **零外传**：数据直接从你本机发往 ESI，不经过任何第三方服务器；令牌本机加密保存。
- **仅欧服**：固定使用 Tranquility（`datasource=tranquility`），没有国服切换。

**界面结构**（与参考站点一致的三段式布局）：

## 一、三步开始用

### 0. 先决定用哪种方式（二选一）

| 方式 | 需要 Python 吗 | 体积 | 适合 |
|---|---|---|---|
| **便携版**（推荐） | **不需要** | 解压后约 40 MB | 任何人。解压 → 双击 `start.bat` |
| 源码版 | 需要 Python 3.8+ | 约 600 KB | 开发者，或想读/改代码 |

> **不想自己构建？直接下载现成的便携包：**
> [Releases](https://github.com/zhp8059/eve-industry-calculator/releases/latest)
> → `eve-industry-portable-<版本>.zip`
> （约 17 MB，解压即用，内置 SDE 数据，首次启动无需下载 95 MB）
>
> 每个 Release 的说明里都列了 **SHA-256**。本程序没有代码签名证书（个人项目，
> 证书要按年付费），所以校验和就是核对「下到的东西有没有被动过」的方式：
>
> ```powershell
> Get-FileHash .\eve-industry-portable-0.6.1.zip -Algorithm SHA256
> # 与 Release 说明里的 SHA-256 对比，一致即可
> ```

**便携版**自带了官方的免安装 Python 运行时（`runtime/`），不写注册表、不需要管理员权限、
删除文件夹即完全卸载。本仓库默认**不包含**运行时（避免把 11 MB 二进制塞进 git），
双击 **`打包便携版.bat`** 即可一键生成：

```
双击 打包便携版.bat
  → 自动下载官方 python-3.13.16-embed-amd64.zip（约 11 MB，走 python.org 官方地址）
  → 解包到 runtime/ 并修正搜索路径
  → 跑一遍能力自检（OpenSSL / SQLite / DPAPI / ESI 连通）
  → 产出 build/eve-industry-portable.zip
```

> 构建这一步需要一个 Python（用来跑下载脚本）；构建完成后，
> **生成的便携包自己带运行时，分发给别人时对方无需安装任何东西**。

### 1. 启动

双击 **`start.bat`**。浏览器会自动打开 `http://127.0.0.1:8420/`。

`start.bat` 会**优先使用 `runtime\python.exe`**（便携版），找不到才回退到系统安装的 Python 3.8+。
命令行用法：`start.bat --port 9000`、`start.bat --no-browser`、`start.bat --check`（只做环境自检）。

### 2. 导入静态数据（首次必做）

第一次启动时会**自动在后台下载并导入**官方 SDE（约 95 MB，实测约 2 秒导入完）。
也可以手动到「设置 → 静态数据」点「下载并导入最新 SDE」。

> 便携包里如果带了 `data/industry.db`（构建时默认包含），首次启动**无需再下载**。

### 3. 登录你的角色

**直接点右上角绿色的「登录 EVE」按钮就行 —— 本程序已内置 Client ID，不用注册任何应用。**

登录是**一键、自动**的：

```
点右上角「登录 EVE」→ 弹窗里点「前往 EVE 授权页面」
   ↓ 同标签页跳转（不走弹窗，所以不会被浏览器拦截）
EVE 官方登录页：登录账号 → 选角色 → AUTHORIZE
   ↓ 浏览器自动跳回本机 /callback，程序在后台用 code + PKCE 换令牌
自动拉取该角色的工业项目 / 蓝图 / 库存 / 职位 / 技能 + 军团数据
   ↓
自动跳到「工业项目」页，数据已经在了
```

只需要在 EVE 官方页面上点一次 **AUTHORIZE**，其余全程自动。
未授权时顶栏会显示醒目的登录按钮、内容区顶部有提示条，
启动程序时也会自动弹出登录窗口（勾选「以后自动跳转」后下次会倒计时 5 秒自动前往）。

> 如果 EVE 提示回调地址不合法，用登录窗口里的「**回调被拒？手动粘贴授权码**」，
> 把浏览器地址栏整条 URL 贴进去即可。
>
> 点了授权之后如果没自动回来，本程序启动时会弹出**「正在等待角色通过 EVE 登录」**
> 窗口 —— 里面就能直接粘贴授权码，不需要自己去别处找入口。

**不需要注册应用**：程序内置了 Client ID（写在 `app/config.py` 的 `BUILTIN_CLIENT_ID`），
界面上不显示、也不会写进你的本地配置。想改用**自己注册的应用**（例如军团内部自建），
把 Client ID 填到「设置 → EVE 应用凭据」即可覆盖内置值。

登录后到「工业项目」点「从 ESI 刷新」，即可看到个人与军团工业项目。

## 二、功能一览

| 你要的功能 | 界面位置 | 说明 |
|---|---|---|
| **个人 + 军团工业项目** | 「工业项目」 | 状态、活动、流程数、成功/许可次数、概率、地点、起止时间、剩余时间、ESI 真实费用；含进行中任务的时间线图 |
| **蓝图 / 材料清单与成本利润（含 ME/TE）** | 「蓝图计算」 | 主界面。可同时加入多个产品，逐个设 ME/TE/流程数；自动聚合出原料明细表 |
| **ME / TE 研究时间模拟** | 「研究模拟」 | 算出材料效率与时间效率研究在**各类建筑**里各需要多久，逐级明细、设施对比、费用估算；可读取自己持有的蓝图，直接看「研究到满级还要多久」 |
| **市场行情 / 利润排行** | 「利润排行」「价格对比」 | 按利润率/单件利润/每小时收益排序；盘口（最低卖单、最高买单）与 30 天历史 |
| **一键刷新物价并保存到本地** | 顶栏「物价」按钮 / 设置 / 价格对比 | 5 档刷新范围（调整价 → 成本指数 → 盘口 → 历史），后台任务带进度，全部写入 `data/industry.db`；按钮会显示上次更新时间，超过 12 小时高亮提醒 |
| **生产规划 / 库存** | 「生产规划」「库存」 | 多级 BOM 逐层展开、自动用库存抵扣、给出采购清单与串行耗时估算 |
| **多角色 / 多军团** | 顶栏角色选择器 | 支持多角色登录切换，或个人库/军团库分别查看 |
| **按需授权（最小权限）** | 登录弹窗 | 两档可选：只授权个人数据（8 项）或 个人 + 军团（13 项）。选个人档后军团页面会提示「追加授权」，点一下即可补上 |

界面布局与配色参考了 `http://www.ceve-industry.cn/`（已按要求**不做友情链接**）。

### 刷新物价（把 ESI 市场数据存到本地）

顶栏有一个 **「物价 ↻」** 按钮，点开就是刷新面板。它会在后台把 ESI 的市场数据拉下来，
**写入 `data/industry.db`**，下次启动直接可用（也会遵守 ESI 自己的缓存时间，不会被判定为绕过缓存）。

| 范围 | 请求量 | 拿到什么 |
|---|---|---|
| 只刷新 CCP 调整价 / 平均价 | 1 次 | 全部约 16,000 个物品的调整价与平均价 —— **EIV（估算物品价值）用的就是调整价** |
| + 系统成本指数 + 工业设施 | 3 次 | 每个星系的工业成本指数（决定任务费用）、可用的生产设施清单 |
| + 当前涉及物品的吉他盘口 | 每个物品 1~2 次 | 最低卖单 / 最高买单 —— 算真实市价与利润率需要它 |
| + 历史成交（近 30 天） | 每个物品 1 次 | 「近 7 日成交均价」这个价源 |
| 全都刷新 | 以上全部 | 首次使用建议选这个 |

「当前涉及的物品」是自动汇总出来的：蓝图计算里的产品与原料、生产规划的材料、
研究模拟的目标、正在查价的物品。单次上限默认 **250 个物品**（`config.json` 里的
`market_refresh_max_items` 可调）。

面板里同时显示**本地已保存什么**：调整价多少条、盘口多少条、历史多少行、各自更新时间、
数据库体积 —— 所以「保存在本地」是看得见的。刷新是后台任务，带进度与分步结果（哪一步失败会明确列出来）。

> 注意区分两种价格：**调整价**是 CCP 官方给的全局参考价（EIV 用它，与市场无关）；
> **盘口**是某个星域实际的挂单（吉他最低卖单等）。要算利润率就得刷盘口。

### 研究模拟（ME / TE）

选中一张蓝图（或从「我的蓝图」点进来），设定研究范围与设施，就能得到：

- **各设施对比表**：NPC 空间站、莱塔卢 / 阿兹贝尔 / 索迪约 / 各色铁壁（可再叠加实验室优化改装件），
  列出时间倍率、ME/TE 耗时与费用、以及「相对最快差多少」
- **逐级明细**：第 1~10 级每一级的基准耗时、实际耗时、累计值与本级费用
- **安等倍率**：高安 ×1.0 / 低安 ×1.9 / 00 与虫洞 ×2.1（改装件减免会按安等放大）
- **我的蓝图**：读取你角色/军团持有的蓝图，按「研究到满级还要多久」排序，一键载入模拟

等级模型（已用官方 SDE 校验，详见 [docs/公式与数据来源核实.md](docs/公式与数据来源核实.md)）：

```
等级表（rank=1 时的累计秒数）: 105 / 250 / 595 / 1414 / 3360 / 8000 / 19000 / 45255 / 107700 / 256000
第 n 级本身耗时 = 累计(n) − 累计(n−1)            ← 表内是累计值，不是每级增量
第 n 级基准     = SDE 研究时长 × 累计(n) / 累计(1)  ← 以官方 SDE 的时长为基准，按比例外推

实际耗时 = 基准 × Π(结构时间倍率 2602) × Π(1 + 改装件时间减免 2593 × 安等 / 100)
                 × Π(1 − 技能每级减免 × 等级)

ME 与 TE 各有 10 个等级：ME 每级 −1%（显示 0–10），TE 每级 −2%（显示 0–20）
```

以裂谷级蓝图（rank 20）为例，0→10 级满级研究：**NPC 站 37天18小时**，
**索迪约 + 屹立超大型实验室优化 I 为 21天3小时（省 43.7%）**。

### 主界面（蓝图计算）的表格字段

按参考站点的信息结构组织，字段名做了更准确的调整：

| 列 | 含义 |
|---|---|
| 原料名称 | 聚合后的原料，带图标与「可用于哪些产品」 |
| 原料类别 | 所属分类（如 建筑组件、有生货物） |
| **来源** | 逐个原料切换「**自造 / 收购**」 |
| 生产地点 | 取当前选择的生产星系 |
| 平均消耗数量 | 该原料总需求量 |
| 可用库存数量 | 库存数量，不足时标红显示缺口 |
| 单件成本 | 自造时 = （子材料 + 任务费用）单价；收购时 = 市场单价 |
| 单价 | 市场单价（价源可配） |
| 总价 | 数量 × 单价 |
| 总利润 | (单价 − 单件成本) × 数量 |
| 利润率 | 总利润 ÷ (单件成本 × 数量) |
| 体积(m³) | 数量 × 单件体积 |

顶部三张汇总卡与参考站点一致：**总成本 / 总价格 / 利润率**，
其中 `利润率 =（总价格 − 总成本）÷ 总成本`。

## 四、公式与依据（摘要）

完整依据、实测向量与「未核实项」清单见 **[docs/公式与数据来源核实.md](docs/公式与数据来源核实.md)**。

```
# 材料数量（乘完流程数后向上取整；反应不吃 ME）
材料 = max(流程数, ceil(基准量 × 流程数 × (1−ME/100)
                        × Π(结构材料倍率 2600)
                        × Π(1 + 改装件材料减免 2594 × 安等倍率 / 100)))

# 任务时间（技能、蓝图 TE、结构、改装件全部相乘）
时间 = 基础时间 × 流程数 × (1−TE/100)
       × Π(结构时间倍率 2602) × Π(改装件时间减免 2593 × 安等)
       × Π(1 − 技能每级减免 × 等级)

# 估算物品价值（与 ME、建筑、改装件都无关）
EIV = round(Σ(ME0 基准材料量 × 流程数 × adjusted_price))

# 任务费用
计费基数 = EIV（制造/反应）｜EIV×2%（拷贝/发明）｜EIV×2%×秒数/105（研究）
总费用   = 计费基数×成本指数×费用倍率 + 计费基数×4%(SCC) + 计费基数×设施税 + 计费基数×Alpha税

# 利润率
利润率 = (总价格 − 总成本) ÷ 总成本
```

关键数值与来源：

| 项 | 取值 | 来源 |
|---|---|---|
| SCC 附加费 | **4%**（2024-02-01 起） | 官方 patch notes 转述 + 实测 |
| 设施税率 | NPC 站 0.25%，玩家建筑上限 10% | 官方转述 |
| 材料取整 | **向上取整**，取整在乘流程数之后 | 实测向量（见测试） |
| 技能时间减免 | **相乘**，不相加 | 实测（6000→4080 秒） |
| 结构/改装件叠加 | **相乘** | 实测（Raitaru+rig→2774 秒） |
| 改装件安等倍率 | 高安 1.0 / 低安 1.9 / 00 与虫洞 2.1 | 官方 SDE 属性 2355/2356/2357 |
| 结构加成 | 直读 SDE 属性 2600/2601/2602 | 官方 SDE |
| 成本指数 | `ESI /industry/systems/`（吉他 manufacturing = 0.1665） | 官方端点，程序内实读一致 |

## 五、安全说明

完整设计（含威胁模型、每条取舍的理由、与参考实现的差异）见
**[docs/令牌与登录安全.md](docs/令牌与登录安全.md)**。要点：

- **令牌加密落盘**：**访问令牌与刷新令牌都加密**后写入 `data/industry.db`。
  Windows 默认用 **DPAPI**（密文与当前 Windows 用户绑定，把 `data/` 整个拷走也解不开）；
  其它平台用 **AES-256-GCM**（纯标准库实现，密钥来自 `EVE_TOKEN_ENCRYPTION_KEY`
  或自动生成的 `data/token.key`）。
- **密文绑定到角色与字段**：AAD 是 `character:<角色ID>:<access|refresh>`，
  把某个角色的令牌复制到另一个角色、或把 refresh 当 access 用，都会解不开。
- **验签失败就拒绝登录**：RS256 + JWKS，校验 `iss` / `exp` / `aud`（必须同时含本应用
  client_id 与 `"EVE Online"`）/ `sub`；`kid` 未命中会先强制刷新 JWKS。
  **不会**因为「验签麻烦」就退回到未验签的身份。
- **本机来源校验**：只接受 `Host` 为本机的请求（防 DNS rebinding），
  带 `Origin` 的请求必须正好是本机这个端口（防 CSRF）。
- **角色转手会被发现**：`owner_hash` 变化时暂停该角色的同步并要求确认，
  绝不用空值覆盖已知的产权记录。
- **刷新失败分类**：只有 EVE 明确说 `invalid_grant` / `invalid_token` 才把角色标成
  「需重新登录」；网络错误、5xx、401（多为 client_id 配错）都不会。
- **并发刷新串行化**：EVE 每次刷新都会轮换 refresh token，同一角色的刷新按锁串行，
  避免两次刷新互相作废（否则表现为「偶尔莫名需要重新登录」）。
- **令牌值绝不进日志**；解密失败只记角色 ID 与异常类型。
- **只请求需要的权限，并且会审计**：默认 13 项全是**读**权限，分两档按需请求
  （见 [docs/令牌与登录安全.md](docs/令牌与登录安全.md) 第十节）。
  代码里有 `audit_scopes()`：一旦 `config.json` 的 scopes 混进
  `send_`/`write_`/`manage_`/`open_window` 这类**能代替你做事**的权限，
  登录会告警、设置页会提示 —— 发邮件、控制游戏客户端、改组舰队这些能力
  本程序一个都用不到。
- **Client Secret 非必需**：默认走 PKCE 公共客户端。若填写了 secret，
  它会明文保存在 `config.json` 中，请注意不要分享该文件。
- **不经过第三方**：所有请求都从本机直接发往 `esi.evetech.net` / `login.eveonline.com` /
  `developers.eveonline.com` / `images.evetech.net`。
- **请勿分享 `data` 目录与 `config.json`**。

## 六、开发者命令

```bat
REM 环境自检（不启动服务）
python -m app.main --check

REM 运行公式回归测试（19 项，对照公开实测数据）
python -m unittest discover -s tests -v

REM 接口验收（需先把服务跑起来，然后改 acceptance.py 顶部的端口）
python tests/acceptance.py

REM 从本地 zip 导入 SDE（离线/加速）
python -m app.main --sde-import D:\path\to\eve-online-static-data-latest-jsonl.zip

REM 启动时不自动打开浏览器、指定端口
python -m app.main --port 9000 --no-browser

REM 启动前清空 ESI 响应缓存
python -m app.main --clear-cache

REM 可选：前端渲染冒烟测试（需要 Node，仅开发用；程序本身不需要 Node）
node tests/ui_render_test.js

REM 构建免安装便携包（等价于双击 打包便携版.bat）
python tools/build_portable.py                # 默认 3.13.16 + 带上已导入的 SDE 数据库
python tools/build_portable.py --latest       # 自动选 python.org 上最新的可用版本
python tools/build_portable.py --no-data      # 不带数据库，包更小
python tools/build_portable.py --force        # 重新下载并解包运行时
```

`tests/` 里三个测试的分工：

| 文件 | 需要 | 覆盖内容 |
|---|---|---|
| `test_formulas.py` | 仅 Python | 19 项工业公式回归，逐条断言公开实测向量 |
| `acceptance.py` | 运行中的服务 | 17 项接口与静态资源验收 |
| `ui_render_test.js` | Node（可选） | DOM 桩渲染 7 个视图，16 项渲染 + 21 项内容断言，防止模板字段写错 |

测试覆盖的实测向量（全部断言在 `tests/test_formulas.py`）：

- 裂谷级蓝图 ME0 / ME10 的材料数量
- 莱塔卢(0.99) × 改装件 37180(材料 −2%) → `32000→31047`、`6000→5822`、`2500→2426`、`500→486`
- 弹药蓝图 2515 的 `ceil` 取整向量（ME2/5/7）与「先乘流程数再取整」
- 「每流程至少 1 个」边界
- 技能相乘（6000→4080 秒）、TE 相乘（→3264 秒）、建筑+改装件相乘（→2774 秒）
- EIV 与 ME / 建筑 / 改装件无关（恒为 349806）
- 计费基数按活动区分、SCC = 4%、费用减免只作用于系统费用部分
- 改装件的安等倍率与作用范围过滤
- 索迪约材料聚合结果包含参考站点里出现的全部条目

## 七、已知限制

1. SDE 的成本指数只给 4 位小数，估算与游戏内实扣费用约有 **0.004%** 差异。
2. 改装件加成默认按**高安 ×1.0**；若生产星系未知，可在「蓝图计算」页手动选择安等倍率。
3. 玩家建筑的**已安装改装件**无法通过 ESI 读取（ESI 不暴露建筑装配），
   需要在界面上手动选择；建筑本身的加成若角色有权限则自动读取。
4. 研究类任务的费用公式来自社区推算（官方未公开）；界面里单独标注。
5. 军团工业项目需要 **工厂经理** 或 **总监** 职位；军团蓝图与资产需要 **总监**。
   程序会在「设置 → 职位检查」里明确告诉你缺什么。
6. 盘口（最低卖单 / 最高买单）按物品逐个查询 ESI，一次最多 160 个物品，
   超出部分自动回退到调整价并在界面上提示。
7. 不包含 T3 逆向工程、行星工业（PI）、采矿与合同相关计算。
8. **便携版目前只支持 64 位 Windows** —— 内置的是官方 `embed-amd64` 运行时（python.org 只发布
   Windows 版 embeddable 包）。macOS / Linux 用户可以用源码版（装个 Python 3.8+ 即可），
   代码本身只用标准库、没有平台相关依赖，但**刷新令牌的 DPAPI 加密是 Windows 专属**，
   其它平台会退化为明文并在界面上显示「明文」标记。
