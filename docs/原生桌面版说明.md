 原生桌面版（v0.9.x）

从 v0.9.0 起，程序是**完全本地的桌面程序**（tkinter），不再需要浏览器，也不再常驻
本地网页服务。计算、研究模拟、市场浏览全部在本进程内完成。

## 安装与首次使用

1. 到 [Releases](https://github.com/zhp8059/eve-industry-calculator/releases/latest) 下载
   `eve-industry-desktop-windows.zip`，解压到任意目录（**不要**放在需要管理员权限的目录）。
2. 双击 `EVE工业计算器.exe`。
3. 首次使用是空库，先到「设置 → 静态数据」点 **下载并导入最新 SDE**（约 95 MB）。
   导入期间界面仍可用，有进度条，可取消。
4. 需要自己的工业项目/库存时，点工具栏 **登录 EVE**（官方 SSO + PKCE）。

数据都放在 **EXE 所在目录**：`data/industry.db`（缓存 + 令牌，令牌加密存放）、
`data/icons/`（物品图标，下载一次后离线可用）、`config.json`。
**升级时只替换 EXE 与依赖目录即可，data/ 不会被覆盖。**

## 十个标签页

| 标签 | 说明 |
|---|---|
| 物品 | 左侧游戏同款市场分组树（懒加载）；物品行显示图标与「蓝图原本」 |
| 蓝图计算 | ME / TE / 流程数可调，材料表 + 成本/时间汇总 |
| 研究模拟 | ME/TE 从→到区间，8 种设施方案对比 |
| 工业项目 | 角色/军团工业项目（需登录） |
| 库存 | 角色/军团库存 + 搜索（需登录） |
| 生产规划 | 多级 BOM 计划 + 购物清单 |
| 利润排行 | 当前物品列表按利润排序（后台计算） |
| 价格对比 | 调整价 / 平均价 / 最低卖单 / 最高买单 / 价差 |
| 设置 | SDE 导入、物价刷新、数据库重建、图标预取 |
| 关于 | 数据来源、非官方声明、隐私说明 |

## 登录用的本地回调端口

EVE SSO 只支持把授权码重定向到 **http URL**，不支持自定义协议。所以原生版在
**登录期间**临时监听 `http://localhost:8420/callback` 接收一次回调，拿到授权码后
立即关闭 —— **平时不监听任何端口**。

若该端口被占用（例如旧的网页版还在运行），程序会**明确报错**而不是静默失灵
（Windows 上 `HTTPServer` 默认允许同端口重复绑定，曾导致回调被别的监听者接走）。

## 命令行

```powershell
# 无头自检：构建全部控件并跑通数据路径后退出（CI 用；空库时只验界面）
EVE工业计算器.exe --self-test

# 从源码运行（需要完整 Python，便携运行时不含 tkinter）
python -m desktop.main
python -m desktop.main --self-test
```

## 从源码构建 EXE

```powershell
python -m pip install pyinstaller==6.11.1
pyinstaller --noconfirm --clean "desktop/EVE工业计算器.spec"
# 产物：dist/EVE工业计算器/
```

CI（`.github/workflows/build-desktop.yml`）会自动跑：
内核单元测试 → 原生无头自检 → PyInstaller 打包 → **打包产物再自检** → 上传 Artifact/Release。
若自检失败，CI 会把输出写成 `ci-selftest.log` 提交回仓库，便于直接看失败原因
（Actions 步骤日志在部分网络环境下不易读取）。
