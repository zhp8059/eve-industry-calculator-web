# 原生版 ↔ 网页版 功能对照（补齐清单）

> 用户要求：**根据网页版增加各模块的功能**。
> 现状：原生版十个视图都在，但每个模块的功能比网页版薄；网页版（v0.1–v0.8）的界面代码
> 已随 v0.9 重构退役，但**内核（`app/*.py`）完整保留** —— 所以补齐是"界面接线"工作，
> 公式与数据来源不需要重写。

## 实施顺序建议

1. **设置页的「工业计算参数」+「角色与缓存表格」** —— 这两块影响所有计算与日常使用（配置项、角色管理）
2. **蓝图计算的「生产设施」+「燃料消耗」+「任务计费参数」** —— 网页版最核心的差异，且内核函数齐备
3. **工业项目的「状态筛选 + 时间线」**、**生产规划的「目标产品 + 层数」**
4. **利润排行的「排序/分类/ME-TE/刷新盘口」**、**价格对比的「盘口查询 + 历史」**
5. 设置页其余（市场与价源、SDE 统计明细、物价明细、方案管理）

## 约束

* 每项都**接到既有内核函数**，不重复实现公式（公式已逐条核实，见 `docs/公式与数据来源核实.md`）
* 每项加**无头自检断言**（可断言"控件存在且调用后拿到结构"）
* 内核 156 项单元测试保持全绿
* 每项按既有流程递增版本并发布
